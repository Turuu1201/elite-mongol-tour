# Elite Mongol Tour: аяллын компанийн вэбсайт

Аялал үзүүлэх, онлайнаар захиалга авах, ажилтан захиалгыг удирдах вэбсайт.

| Хэсэг | Технологи | Хавтас |
|---|---|---|
| Frontend | Vite + React + TypeScript + Tailwind CSS | `client/` |
| Backend | Node.js + Express + Zod | `server/` |
| Өгөгдлийн сан | PostgreSQL (орон нутагт PGlite, production-д Neon) | `server/src/schema.ts` |
| Байршуулах | Netlify (вэб + API функц), Neon (өгөгдлийн сан) | `netlify.toml` |

## Компьютер дээр ажиллуулах

```bash
npm run setup     # бүх сангуудыг нэг удаа суулгана
npm run dev       # API (4000) ба вэб (5173) хоёуланг асаана
```

Дараа нь браузерт http://localhost:5173 хаягийг нээнэ.

- Анх асаахад `server/.data/pg` хавтсанд PostgreSQL өгөгдлийн сан үүсэж, 8 жишээ аялал автоматаар орно.
- Өгөгдлийг цэвэрлэх бол серверийг зогсоогоод `server/.data` хавтсыг устгана.
- Админ хэсэг: http://localhost:5173/admin. Нууц үг нь `server/.env` файлын `ADMIN_PASSWORD`.

## Хэл (Монгол / English)

- Header дээрх **МН / EN** товчоор солино. Сонголт браузерт хадгалагдана.
- Үндсэн хэл нь монгол. `?lang=en` гэсэн холбоос (жишээ нь `/tours/govi-ikh-aylal?lang=en`) англиар шууд нээгдэнэ.
- Интерфейсийн бүх текст: `client/src/lib/i18n.tsx` (`mn` ба `en` толь бичиг).
- Аяллын агуулгын орчуулга: өгөгдлийн сангийн `tours.translations` баганад (`{"en": {...}}`), жишээ өгөгдөл нь `server/src/seed-en.ts`.
  Орчуулга байхгүй талбар монголоор харагдана.
- Серверийн алдааны мессеж `?lang=` параметрийн дагуу хоёр хэлээр гарна (`server/src/app.ts` → `MESSAGES`).

## Хандалтын хяналт (Analytics)

`/admin` → **Хяналт** таб. 7 / 30 / 90 хоногоор:

- Зочид, хуудас үзсэн, аялал үзсэн, захиалга, захиалгад шилжсэн хувь (өмнөх үетэй харьцуулсан)
- Өдөр бүрийн зочдын график (хулганаар заахад дэлгэрэнгүй; «Хүснэгтээр» товч)
- Аялал бүрээр: үзсэн, зочид, маягт нээсэн, захиалга, хөрвөлт
- Захиалгын замнал: сайтад орсон → аялал үзсэн → маягт бөглөж эхэлсэн → захиалга илгээсэн
- Төхөөрөмж, хэл, хаанаас орж ирсэн, түгээмэл хайлтууд, их үзсэн хуудсууд, сүүлийн үйлдлүүд

**Юу бүртгэдэг вэ:** `page_view`, `tour_view`, `search`, `filter`, `booking_start`, `booking_submit`, `lang_switch`
(`client/src/lib/track.ts` → `POST /api/events` → `events` хүснэгт).

**Хувийн нууц:** IP хаяг, нэр, имэйл хадгалахгүй. Зочныг браузерт үүссэн санамсаргүй ID-гаар (localStorage) тоолно.
«Do Not Track» асаалттай браузер, бот/crawler, админ хуудсыг бүртгэхгүй.
Сайтдаа нууцлалын бодлогын хуудас нэмж, энэ тухай дурдахыг зөвлөж байна.

## Хуудсууд

- `/`: нүүр хуудас (хайлт, онцлох аялал, бүс нутаг, сэтгэгдэл)
- `/tours`: бүх аялал, шүүлтүүртэй (бүс, төрөл, хугацаа, үнэ)
- `/tours/:slug`: аяллын дэлгэрэнгүй ба захиалгын маягт
- `/admin`: захиалга баталгаажуулах/цуцлах, аялал нэмэх/засах, аяллыг нуух/онцлох

## Админаас аялал нэмэх

`/admin` → **Аялал** таб → **Шинэ аялал** (эсвэл аялал бүрийн **Засах** товч).

- Агуулгыг **Монгол / English** табаар оруулна. Монгол нэр, товч ба дэлгэрэнгүй тайлбар заавал; англи хэсэг заавал биш.
- URL хаяг монгол нэрээс автоматаар латинаар үүснэ (Хустайн нуруу → `khustain-nuruu`). Гараар засаж болно.
- Зургийг холбоосоор (мөр бүрт нэг URL) оруулна, эхний зураг нь гол зураг болно.
- Өдөр тутмын хөтөлбөрийн өдрүүдийг нэмж, хасаж, дээш доош зөөж болно.
- Шинэ аялал сэтгэгдэлгүй тул "Шинэ" тэмдэгтэй харагдана.
- Захиалгатай аяллыг устгахгүй, харин **Идэвхтэй** унтраалгаар сайтаас нуудаг.

## Netlify дээр байршуулах

Нэг Netlify сайт: вэб (`client/dist`) + API (`netlify/functions/api.ts` → `server/src/app.ts`).
Тохиргоо нь `netlify.toml`-д; `/api/*` хүсэлтүүд Express функц рүү очно.

1. **Өгөгдлийн сан:** [neon.com](https://neon.com)-д Free акаунт нээж, **AWS US East 2 (Ohio)** бүсэд төсөл үүсгэнэ
   (Netlify Functions мөн тэнд ажилладаг). Connection string (pooled)-ийг хуулна.
2. **Netlify сайт:** GitHub репог холбоно (Build command, publish dir-ийг `netlify.toml`-оос автоматаар уншина).
3. **Environment variables** (Site configuration → Environment variables):
   - `DATABASE_URL`: Neon-ий холбоос
   - `ADMIN_PASSWORD`: хүчтэй нууц үг
   - `SESSION_SECRET`: 32-оос дээш тэмдэгттэй санамсаргүй мөр
   - `NOTIFY_EMAIL`, `SMTP_USER`, `SMTP_PASS`: захиалгын имэйлд (дээрх хэсгийг үз)
   - `SITE_URL`: сайтын хаяг (имэйл дэх «Удирдлага руу орох» холбоосонд)

Анхны хүсэлт ирэхэд хүснэгтүүд болон жишээ аяллууд автоматаар үүснэ.

**Netlify Free хязгаар:** сард 300 кредит (production deploy бүр 15 кредит, 1 GB урсгал 20 кредит).
Хэтэрвэл сайт дараагийн сар хүртэл зогсоно, тиймээс өөрчлөлтөө нэгтгэж цөөн deploy хийнэ.
